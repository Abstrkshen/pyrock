# langchain

Formats a prompt and runs it through a LangChain chain. Uses the virtualenv at `../../.venv`.

<!-- readme_check: skip-ci (needs the examples virtualenv, see ../../README.md) -->

```sh
pyrock check main.py --python ../../.venv/bin/python
pyrock explain main.py --python ../../.venv/bin/python
pyrock run main.py --python ../../.venv/bin/python
```
